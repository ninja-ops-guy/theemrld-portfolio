# QA gates — fail closed where evidence is absent

## P0 — cannot ship
- Wrong actor identity/face conflation; K/Red/El mistakenly duplicated; Iona looks like Felicia; Oz mask assigned to Red; wrong dog identifiers.
- Event/knowledge violation: Mike knows K's face before Ghost Fork, wrong escape order/cells, unsupported memory source, accidental omnipotence on Earth, secret cosmology declared as fact.
- Missing required scene beat/page (including car-gap jump when mandated), same scene art/page accidentally repeated, malformed/broken PDF or inaccessible export.
- Visually false statement about verified state: art marked APPROVED though likeness references were never checked; code checker alone asserted face similarity.

## P1 — must fix before release
- Distinct hair, outfit, accessory, skin tone or face drift against approved model sheet; costume swap without scene event; comic/game style mismatch.
- Wrong driving perspective or screen-direction continuity; motion impossible across cuts without a transition; dialogue balloon points to wrong speaker.
- Lettering intersects art, face cropped, aspect ratio not 2:3, page unreadable on mobile, unintended page-number jump, duplicate chapter/page heading.
- Music credits or GHOST BENDS song details asserted without discography evidence; unapproved new song/credit.

## P2 — issue log + editorial review
- Loose word choice, overly expositional lines, humor undercutting consequence, color accents drifting without a meaningful reason, weak scene transitions, optional staging proposals presented without a PROPOSED label.

## Required review record
1. Source v1.7 hash verified; latest creator updates checked against active scope.
2. Exact deliverable files enumerated and opened, with hashes and intended page count.
3. Every page inspected at full size **and mobile size**. All expected beats present once, in sequence; no duplicate art unless intentional and labeled.
4. Each face-bearing panel compared with actual approved image reference, not only textual description.
5. Every scene checked for who knows what, narrative tense, channel, event order and authority.
6. Panel-to-panel camera axis, hands, costume, objects, colors, lighting and dialogue checked.
7. Report issue severity + precise page/panel + fix + retest evidence.
8. Only `READY` when P0/P1 = 0, visual checks complete, and required owner approvals recorded. Otherwise `BLOCKED` or `PROVISIONAL`.
