# See World — public presentation pass

Scope: public interface and onboarding only. No new story scene, chapter rule,
identity disclosure, authored dialogue, operation, or visual likeness is created.
Source authority remains Story Bible v1.7 and the already released linked campaign.

## Delivered surfaces
- Branded responsive media hub with a clear comic entry, direct main-game entry,
  See World, art gallery, K Terminal, SoundCloud and creator-supplied social handles.
- Copy-link control with selectable-text fallback when clipboard permission fails.
- See World welcome, three-step journey guide, differentiated locked/available
  perspective cards, timeline styling and a responsive narrative reader.
- Explicit old-save onboarding: Continue, then Linked Story; never reset a run to link.
- Local-only reader preferences (larger type and focus mode), outside all game keys.
- Accessible help dialog, expandable save tools, reduced-motion and forced-colors
  support, and a useful module-loading failure page instead of an empty interface.

`presentation.mjs` is a DOM-only progressive enhancement. It never reads native
saves, imports narrative manifests, enables a disabled choice, or writes progression.
It uses only already-disclosed DOM content. `player.mjs` contains loading recovery.
Core `linked-app.mjs`, `linked.mjs`, `engine.mjs`, `campaigns.mjs`, isolated preview
and every native game file remain byte-for-byte unchanged from the released pair.

The visual motif is abstract interface geometry, not a new character, location,
portrait, costume, canonical power or promised cinematic. All faces/likeness review
is NOT APPLICABLE. Existing narrative staging remains provisional, with that
limitation retained in player help/footer and the original scene manifest.

Social handles are owner-provided destinations, not independently verified account
claims. Removing the development-only “profile unverified” subtitle does not add a
verification badge. SoundCloud is labeled by its actual destination @raikouno,
without inventing music credits or releases.

## Test scope
Keep the unchanged 81-case recovery matrix and original linked/browser suites.
Add built-site presentation acceptance: mobile/desktop layouts, exact destinations,
clipboard fallback, help focus/Escape, text controls, preferences isolation, no
spoilers, no unintended storage writes, main-reader failure, enhancement failure,
and native story choice/progression regression. Screenshots must be inspected.

The pass does not claim new 3D campaign maps, cinematics, voice performances,
cloud saves, physical-device certification or an uninterrupted full-game playthrough.
