Recover Saved Settings

Your earlier settings may still exist on ninja-ops-guy.github.io, in the browser and device where you used the site. A new domain cannot read them directly. Nothing on this page clears your old data.

1. Export on the original website

Close other K Terminal and comic tabs, then open the recovery page on the original origin in the same browser you used before. Export your bookmarks, playlists and settings as a JSON file.

Open original-origin recovery ↗

2. Preview the file here

Open that JSON file below. Missing settings are selected by default. Replacing a setting already present here requires selecting it explicitly. A backup of the affected current values is saved before any change.

Choose a file to preview. Nothing will change until you import.

Game and See World saves

This tool does not copy or merge game saves, playthrough IDs, milestones or See World progress. Use the original game origin for your existing game save. The paired connected-reader repair keeps See World beside that game; its availability depends on deployment of the native reader.

Open the original TechOps Hero game. Do not start a new game or clear browser storage to recover an existing run.

If the original-origin recovery page is not available yet, keep your old browser data and retry after the companion update is deployed. If you already cleared that data and have no backup, this tool cannot reconstruct it.
